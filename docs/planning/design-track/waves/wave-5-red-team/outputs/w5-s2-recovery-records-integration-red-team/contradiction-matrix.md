# w5-s2 contradiction matrix

## Legend

- `coherent`: the cited sources align at probe altitude.
- `under-specified`: the cited sources point to the same intended behavior but leave an integration
  seam insufficiently closed.
- `contradiction pressure`: the cited sources pull in different directions or leave a reader unable
  to reconstruct one coherent integrated behavior.
