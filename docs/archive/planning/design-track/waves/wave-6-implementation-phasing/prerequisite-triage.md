# Wave 6 prerequisite triage

This artifact classifies Wave 5 red-team findings before Wave 6 phases implementation. It does not
resolve any finding locally, edit `docs/design/**`, freeze schemas, assign new `INV-*` numbers, or
create implementation work. Planning may only sequence, gate, and route.

## Classification Key

Each row uses exactly one classification:

1. Must resolve before Wave 6 can phase implementation.
2. May proceed only if converted into an explicit implementation stop condition.
3. May proceed if converted into an explicit evidence/test requirement.
4. Deferred to a named later owner, with rationale and no hidden dependency.
5. Already resolved by current design, with citations.

## Bottom Line For Wave 6

No Wave 5 item blocks Wave 6 from authoring implementation phasing, because each unresolved item can
be carried as an explicit stop condition, evidence/test requirement, or routed owner dependency.
Several items do block future implementation of specific phases until their stop/evidence gate is
satisfied. Wave 6 therefore phases work around those proof surfaces rather than silently resolving
them.
