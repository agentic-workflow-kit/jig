## Preservation and link policy

The reset preserves archived semantic prose; the final baseline comparison records the exact
destination-only Markdown substitutions. No repair was needed for archived files not listed above.
Repairs target the original evidence: sibling archived files remain sibling links, active guidelines
remain active links, and only the Codex review's external `docs/design/` and `docs/product/` references
gain the one additional `../` required by `raw/reviews/`. The Claude/Fable review is byte-identical.

The reset is editorial and organizational, not a repudiation of explicit owner decisions. Archived
approval and status labels describe the previous iteration and are not current authority; explicit
owner decisions remain binding re-authoring input.

The archive is not a governing layer and must not be used to infer current architecture approval.
