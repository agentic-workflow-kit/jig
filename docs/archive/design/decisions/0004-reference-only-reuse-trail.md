# ADR 0004 — Reference-only reuse trail: cite inline + reuse log

## Context

Owner direction on tracking workflow-kit prior art.

## Decision

Accepted. Citing prototype lessons inline (RL-n) and maintaining
[`prior-art-workflow-kit.md`](../notes/prior-art-workflow-kit.md) as the index of record keeps
the reference-only, re-derive boundary auditable.

## Consequences

Every carried lesson is traceable to a workflow-kit source with a re-derivation rationale;
nothing is ported as architecture.
