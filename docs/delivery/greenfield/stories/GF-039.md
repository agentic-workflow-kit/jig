# GF-039 — Qualified local Git-worktree Execution Host

## Outcome, value, and why now

Propose one separately qualified local Git-worktree provider realization for the semantic workspace contract. The current disposition is deferred: GF-033 remains usable as a semantic contract, but GF-039 provider reachability stays disabled because a same-user durable sidecar is not an independent witness. The conformance probe returns observations/evidence only; it exposes no qualification receipt, public provider factory, or same-process dispatch path. Resume requires an owner-authorized independent qualification evidence carrier, then fresh exact `CF-MECH-WORKSPACE`/`CF-GATE-PROVIDER` evidence and review. Do not claim full GF-039 qualification, autonomous restore, or support for remote/Windows modes, sessions, acceptance, delivery or landing.

## Governing paths and stable IDs

mechanism-and-provider-contracts.md owns PORT-WORKSPACE qualification and unreachability until exact evidence; lifecycle catalogue owns operation identity/preserve-before-retire. CF-MECH-WORKSPACE proves contract behavior and CF-GATE-PROVIDER may admit configuration only after GF-022 admission and an explicit current owner or named-delegate implementation request selecting that realization. DR-5 is a proposed provider realization choice, not a waiver of semantics.

### Track mapping

PORT-WORKSPACE is the semantic port. `CB-WORKSPACE` binds one admitted local workspace path and repository at one declared basis; setup additionally binds the recipe digest, freshness-input digest, and separately authorized setup effects. `RT-CONTROLLER` authorizes the exact Operation and `CP-MEDIATOR` validates its manifest, host/resource, repository/path/basis/recipe, and Operation binding before dispatch. It cannot cross repository, workspace, basis, recipe, host, provider manifest, or Operation, and observe/setup authority cannot become preserve/retire authority. CF-MECH-WORKSPACE proves local adapter contract; DR-5 is Configuration-owned proposed provider realization within the proposed local Git-worktree tuple; FC-MECHANISM is host fault/timeout; BND-WAIT-MECHANISM bounds its response; CF-SETUP-FRESHNESS proves exact receipt; CF-GATE-PROVIDER admits configuration only when GF-022 admission and an explicit current owner or named-delegate implementation request selecting that realization bind the manifest/proof. Product routes PC-JIG-8 and PC-CONCEPTS-3 require binding/independence/provider/secret/mechanism proof; PC-JIG-15 and PC-USE-5 require provider gate/authority; PC-JIG-18 workspace/B2 closure; PC-USE-1 bounds/capacity/workspace/observability. ISO-1 dependency isolation, ISO-2 policy resolution, ISO-3 attributable blocks and ISO-4 collision-free isolation apply; STACK-1 vendor-independent guarantees, STACK-2 swappable seams, STACK-3 work-profile agent choice, STACK-4 attested capabilities, STACK-5 authority boundaries, STACK-6 no first-party shortcut and STACK-7 compatible custom providers apply; DRIVE-1 adversarial conformance, DRIVE-2 activation-bound manifest, DRIVE-3 honest posture and DRIVE-4 reusable conformance apply.

## Dependencies plus start evidence

Require GF-022 admission, an explicit current owner or named-delegate implementation request selecting the proposed local Git-worktree tuple, GF-033 semantic contract/scripted CF evidence, and an owner-authorized independent qualification evidence carrier, all observed in this story's execution base/tuple. Start packet records provider build digest, host OS/local Git version, activation-bound resource/posture, manifest/proof age, predecessor commits/tree/evidence, CI/reviewer proof. A successful ad hoc worktree command or same-user sidecar is not qualification.

## In-scope and non-goals

Scope: local Git-worktree adapter and qualification probes for provision/setup/observe/preserve/retire semantics. Exclude remote host, Windows, alternate VCS, agent session, policy changes, acceptance/delivery, durable same-user gate sidecars, and any unqualified fallback. The provider remains unconfigurable until the deferred prerequisite and exact gate pass for the exact build/environment.

## Runtime/product unit, ports, inputs, outputs, identities, persisted facts, authority

RT-CONTROLLER first records intent and authorizes the exact OPC-WS-PROVISION, OPC-WS-SETUP,
OPC-WS-OBSERVE, OPC-WS-PRESERVE, or OPC-WS-RETIRE Operation. CP-MEDIATOR then validates the
manifest, authorizing owner/delegate request, ID-OP/ID-MANIFEST/ID-STORY/ID-CAND, and every
repository, path, basis, receipt, and generation binding before dispatching through PORT-WORKSPACE
only to the local provider admitted by GF-022; missing or unverifiable authorization or binding
fails closed before dispatch. The result binds manifest/build/host/posture, the
SCH-SETUP-RECEIPT workspace/host identity field, CB-WORKSPACE resource/path binding, canonical
repository/basis/cleanliness, receipt, and preservation; RT-CONTROLLER validates and writes that
fact through the witnessed ledger. The provider performs only the admission-bound mechanism and
cannot transition, choose target, mint evidence/authority, or self-admit.
Manifest/proof/operation/generation fences all others.

## Observable success and terminal outcomes

The local probe can prove native isolation, exact basis/cleanliness/setup freshness, idempotency, crash preservation and destructive-ambiguity containment, but it does not close the deferred independent-evidence prerequisite. Until that prerequisite and exact review pass, CF-GATE-PROVIDER exposes no configuration, receipt, provider factory, or dispatch reachability, including in the probe process. Failure, mismatch or stale proof leaves provider unconfigurable and owning work parked/blocked; it cannot accept, land, release dependency or silently fall back. Remote/Windows always remain unconfigurable.

## Failure, uncertainty, timeout, retry, reconciliation, recovery, cleanup, and resume

Input/basis/path violation FC-INPUT/FC-SUBJECT; stale operation FC-FENCE; host/tool failure FC-MECHANISM; uncertain Git worktree effect FC-EFFECT. Record intent before effect; retry only confirmed absence/re-authorization; otherwise reconcile exact ID-OP/host/workspace fact or park/preserve. BND-WAIT-MECHANISM/RETRY/RECOVERY apply under GF-032. Recovery re-reads real provider facts; uncertain retire preserves workspace and later retirement semantics remain GF-046.

## Security and trust: validation, credentials, redaction, and authority widening

Validate manifest/build/OS/Git/posture, allowed local resource identity, canonical repository/basis, bounded paths, cleanliness and receipt evidence. Credentials resolve in memory only and are absent from worktree facts/logs/evidence. Provider proof/trust root is GF-022 admitted evidence plus an owner-authorized independent qualification evidence carrier and exact real-probe evidence. Stale/ambiguous/self-attested evidence, including same-user sidecar evidence, fails closed; provider/fallback cannot widen filesystem, network or Jig authority.

## Deliverables without delegated algorithm invention

Deliver local Git-worktree adapter, exact manifest/probe harness, and failure/crash fixtures. Do not add a durable same-user qualification sidecar or invent an independent witness carrier. Configuration owns DR-5 implementation only after the deferred prerequisite, GF-022 admission, and an explicit current owner or named-delegate implementation request select the proposed local Git-worktree tuple; constraints are GF-033 semantics, exact manifest, preserve-before-retire and no remote/Windows. Ad hoc host or generic shell provider rejected; widening/change is OWNER_DECISION_REQUIRED for Arye Kogan; blast radius later local execution only.

## Test and evidence obligations

Run real local probes for isolation, basis/cleanliness, fresh/stale setup, idempotent provision, duplicate/lost/uncertain operations, crash recovery, preservation-before-retire, destructive ambiguity, manifest/build/posture mismatch, public configuration absence, same-process provider/dispatch absence, restart-time absence, and every cross-repository/path/basis/recipe/host/manifest/Operation binding. Record host/tool/manifest/proof/request/result/operation/candidate/tree digests, source fixture, independent witness/carrier identity when owner-authorized, and runner. CF-MECH-WORKSPACE and CF-GATE-PROVIDER remain mandatory for any future resumption.

## Exact acceptance

Current acceptance is deferred. An eventual independent non-author review must check the exact provider build/environment/manifest, real-probe package, independent evidence carrier, gate result, candidate/tree and findings. Only that future exact pass may authorize local provider configuration; it does not authorize GF-040 acceptance or GF-044 landing. Partial/stale/self-authored proof or environment drift fails closed and disables configuration.

request, and a fresh gate.
