# GF-039 — Qualified local Git-worktree Execution Host

## Outcome, value, and why now

Propose one separately qualified local Git-worktree provider realization for the semantic workspace contract. It remains inactive until GF-022 provider authority/capability-proof admission and an explicit current owner or named-delegate implementation request select it; GF-033 supplies the contract/fixture. It can then enable a local qualified workspace, not remote/Windows modes, sessions, acceptance, delivery or landing.

## Governing paths and stable IDs

mechanism-and-provider-contracts.md owns PORT-WORKSPACE qualification and unreachability until exact evidence; lifecycle catalogue owns operation identity/preserve-before-retire. CF-MECH-WORKSPACE proves contract behavior and CF-GATE-PROVIDER may admit configuration only after GF-022 admission and an explicit current owner or named-delegate implementation request selecting that realization. DR-5 is a proposed provider realization choice, not a waiver of semantics.

PORT-WORKSPACE is the semantic port. `CB-WORKSPACE` binds one admitted local workspace path and repository at one declared basis; setup additionally binds the recipe digest, freshness-input digest, and separately authorized setup effects. `RT-CONTROLLER` authorizes the exact Operation and `CP-MEDIATOR` validates its manifest, host/resource, repository/path/basis/recipe, and Operation binding before dispatch. It cannot cross repository, workspace, basis, recipe, host, provider manifest, or Operation, and observe/setup authority cannot become preserve/retire authority. Product routes PC-JIG-8 and PC-CONCEPTS-3 require binding/independence/provider/secret/mechanism proof; PC-JIG-15 and PC-USE-5 require provider gate/authority; PC-JIG-18 workspace/B2 closure; PC-USE-1 bounds/capacity/workspace/observability. ## Dependencies plus start evidence

Require GF-022 admission, an explicit current owner or named-delegate implementation request selecting the proposed local Git-worktree tuple, and GF-033 semantic contract/scripted CF evidence, all observed in this story's execution base/tuple. Start packet records provider build digest, host OS/local Git version, activation-bound resource/posture, manifest/proof age, predecessor commits/tree/evidence, CI/reviewer proof. A successful ad hoc worktree command is not qualification.

## In-scope and non-goals

Scope: local Git-worktree adapter and qualification probes for provision/setup/observe/preserve/retire semantics. Exclude remote host, Windows, alternate VCS, agent session, policy changes, acceptance/delivery and any unqualified fallback. The provider may be configured only after its gate passes for the exact build/environment.

## Runtime/product unit, ports, inputs, outputs, identities, persisted facts, authority

CP-MEDIATOR dispatches prior-recorded OPC-WS-PROVISION, OPC-WS-SETUP, OPC-WS-OBSERVE, OPC-WS-PRESERVE or OPC-WS-RETIRE through PORT-WORKSPACE only to the local provider admitted by GF-022 and an explicit current owner or named-delegate implementation request selecting that realization; result binds manifest/build/host/posture, the SCH-SETUP-RECEIPT workspace/host identity field, CB-WORKSPACE resource/path binding, canonical repository/basis/cleanliness, receipt, preservation and catalogued ID-OP/ID-MANIFEST/ID-STORY/ID-CAND. RT-CONTROLLER validates/writes fact through witnessed ledger. Controller authorizes Operations; provider performs only activation-bound mechanism and cannot transition, choose target, mint evidence/authority or self-admit. Manifest/proof/operation/generation fences all others.

## Observable success and terminal outcomes

Qualification proves native isolation, exact basis/cleanliness/setup freshness, idempotency, crash preservation and destructive-ambiguity containment using real local probes. Only then CF-GATE-PROVIDER exposes configuration. Failure, mismatch or stale proof leaves provider unconfigurable and owning work parked/blocked; it cannot accept, land, release dependency or silently fall back. Remote/Windows always remain unconfigurable.

## Failure, uncertainty, timeout, retry, reconciliation, recovery, cleanup, and resume

Input/basis/path violation FC-INPUT/FC-SUBJECT; stale operation FC-FENCE; host/tool failure FC-MECHANISM; uncertain Git worktree effect FC-EFFECT. Record intent before effect; retry only confirmed absence/re-authorization; otherwise reconcile exact ID-OP/host/workspace fact or park/preserve. BND-WAIT-MECHANISM/RETRY/RECOVERY apply under GF-032. Recovery re-reads real provider facts; uncertain retire preserves workspace and later retirement semantics remain GF-046.

## Security and trust: validation, credentials, redaction, and authority widening

Validate manifest/build/OS/Git/posture, allowed local resource identity, canonical repository/basis, bounded paths, cleanliness and receipt evidence. Credentials resolve in memory only and are absent from worktree facts/logs/evidence. Provider proof/trust root is GF-022 admitted evidence plus real probe evidence. Stale/ambiguous/self-attested evidence fails closed; provider/fallback cannot widen filesystem, network or Jig authority.

## Deliverables without delegated algorithm invention

Deliver local Git-worktree adapter, exact manifest/probe harness, failure/crash fixtures and provider-gate evidence recorder. Configuration owns DR-5 implementation only after GF-022 admission and an explicit current owner or named-delegate implementation request select the proposed local Git-worktree tuple; constraints are GF-033 semantics, exact manifest, preserve-before-retire and no remote/Windows. Ad hoc host or generic shell provider rejected; widening/change is OWNER_DECISION_REQUIRED for Arye Kogan; blast radius later local execution only.

## Test and evidence obligations

Run real local probes for isolation, basis/cleanliness, fresh/stale setup, idempotent provision, duplicate/lost/uncertain operations, crash recovery, preservation-before-retire, destructive ambiguity, manifest/build/posture mismatch, config denial before gate, and every cross-repository/path/basis/recipe/host/manifest/Operation binding. Record host/tool/manifest/proof/request/result/operation/candidate/tree digests, source fixture, witness and runner. CF-MECH-WORKSPACE and CF-GATE-PROVIDER are mandatory.

## Exact acceptance

Independent non-author checks exact provider build/environment/manifest, real-probe package, gate result, candidate/tree and findings. This authorizes only local provider configuration, not GF-040 acceptance or GF-044 landing. Partial/stale/self-authored proof or environment drift fails closed and disables configuration.

## DR choices

Configuration owns DR-5 only within the activation-bound local Git-worktree tuple. New provider family, remote/Windows support, changed posture/resource scope or fallback is a widening/change requiring Arye Kogan's owner decision, fresh explicit owner direction, and a fresh gate.

## PR boundary, relative size, and split

Size L; cohesive oracle is exact local provider qualification. Paths: adapter, manifest/probes, fixtures/CF gate evidence; semantic contract excluded. Do not combine with GF-033; GF-033 stays green/unconfigurable while this independently failing realization qualifies.
