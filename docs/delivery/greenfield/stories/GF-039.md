# GF-039 — Qualified local Git-worktree Execution Host

## Outcome, value, and why now

Realize one separately qualified local Git-worktree provider for the semantic workspace contract. It depends exactly on GF-022 provider authority/capability-proof admission and GF-033 contract/fixture; it enables a local qualified workspace, not remote/Windows modes, sessions, acceptance, delivery or landing.

## Governing paths and stable IDs

mechanism-and-provider-contracts.md owns PORT-WORKSPACE qualification and unreachability until current evidence; lifecycle catalogue owns operation identity/preserve-before-retire. CF-MECH-WORKSPACE proves contract behavior and CF-GATE-PROVIDER admits configuration. DR-5 is owner-approved provider realization choice, not a waiver of semantics.

## Dependencies plus start evidence

Require merged GF-022 exact owner-approved manifest, build/environment/posture/resource scope and current capability proof, plus GF-033 semantic contract and scripted CF evidence. Start packet records provider build digest, host OS/local Git version, allowed resource/posture, manifest/proof age, exact baseline, predecessor commits/tree/evidence, CI/reviewer proof. A successful ad hoc worktree command is not qualification.

## In-scope and non-goals

Scope: local Git-worktree adapter and qualification probes for provision/setup/observe/preserve/retire semantics. Exclude remote host, Windows, alternate VCS, agent session, policy changes, acceptance/delivery and any unqualified fallback. The provider may be configured only after its gate passes for the exact build/environment.

## Runtime/product unit, ports, inputs, outputs, identities, persisted facts, authority

CP-MEDIATOR dispatches prior-recorded OPC-WS-* through PORT-WORKSPACE to admitted local provider; result binds manifest/build/host/posture, ID-WORKSPACE, canonical repository/basis/cleanliness, recipe receipt, preservation and ID-OP. RT-CONTROLLER validates/writes fact through witnessed ledger. Controller authorizes Operations; provider performs only selected mechanism and cannot transition, choose target, mint evidence/authority or self-admit. Manifest/proof/operation/generation fences all others.

## Observable success and terminal outcomes

Qualification proves native isolation, exact basis/cleanliness/setup freshness, idempotency, crash preservation and destructive-ambiguity containment using real local probes. Only then CF-GATE-PROVIDER exposes configuration. Failure, mismatch or stale proof leaves provider unconfigurable and owning work parked/blocked; it cannot accept, land, release dependency or silently fall back. Remote/Windows always remain unconfigurable.

## Failure, uncertainty, timeout, retry, reconciliation, recovery, cleanup, and resume

Input/basis/path violation FC-INPUT/FC-SUBJECT; stale operation FC-FENCE; host/tool failure FC-MECHANISM; uncertain Git worktree effect FC-EFFECT. Record intent before effect; retry only confirmed absence/re-authorization; otherwise reconcile exact ID-OP/host/workspace fact or park/preserve. BND-WAIT-MECHANISM/RETRY/RECOVERY apply under GF-032. Recovery re-reads real provider facts; uncertain retire preserves workspace and later retirement semantics remain GF-046.

## Security and trust: validation, credentials, redaction, and authority widening

Validate manifest/build/OS/Git/posture, allowed local resource identity, canonical repository/basis, bounded paths, cleanliness and receipt evidence. Credentials resolve in memory only and are absent from worktree facts/logs/evidence. Provider proof/trust root is GF-022 admitted evidence plus real probe evidence. Stale/ambiguous/self-attested evidence fails closed; provider/fallback cannot widen filesystem, network or Jig authority.

## Deliverables without delegated algorithm invention

Deliver local Git-worktree adapter, exact manifest/probe harness, failure/crash fixtures and provider-gate evidence recorder. DR-5 owner Arye selects initial local Git-worktree realization; constraints are GF-033 semantics, exact manifest, preserve-before-retire and no remote/Windows. Ad hoc host or generic shell provider rejected; gap OWNER_DECISION_REQUIRED; blast radius later local execution only.

## Test and evidence obligations

Run real local probes for isolation, basis/cleanliness, fresh/stale setup, idempotent provision, duplicate/lost/uncertain operations, crash recovery, preservation-before-retire, destructive ambiguity, manifest/build/posture mismatch and config denial before gate. Record host/tool/manifest/proof/request/result/operation/candidate/tree digests, source fixture, witness and runner. CF-MECH-WORKSPACE and CF-GATE-PROVIDER are mandatory.

## Exact acceptance

Independent non-author checks exact provider build/environment/manifest, real-probe package, gate result, candidate/tree and findings. This authorizes only local provider configuration, not GF-040 acceptance or GF-044 landing. Partial/stale/self-authored proof or environment drift fails closed and disables configuration.

## DR choices

DR-5 is bounded above. New provider family, remote/Windows support, changed posture/resource scope or fallback needs new owner decision and fresh gate.

## PR boundary, relative size, and split

Size L; cohesive oracle is exact local provider qualification. Paths: adapter, manifest/probes, fixtures/CF gate evidence; semantic contract excluded. Do not combine with GF-033; GF-033 stays green/unconfigurable while this independently failing realization qualifies.

## Definition of Ready

- GF-022 and GF-033 are merged with exact manifest/proof and semantic CF evidence.
- Build/environment/resource/posture, authority, failure/recovery and gate oracle are explicit.
- DR-5 recorded; provider remains unreachable until current gate passes.

## Definition of Done

- Local Git-worktree provider passes real qualification and only exact admitted configuration can select it.
- Uncertainty preserves/reconciles; remote/Windows/fallback remain unreachable.
- CF evidence, diff check, checks, CI and independent review pass.
